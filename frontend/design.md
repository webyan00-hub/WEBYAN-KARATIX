# DIRECTIVE PERMANENTE — DESIGN UI/UX KARATIX

À partir de maintenant, chaque interface que tu développes ou modernises doit respecter intégralement le Design System KARATIX, la Constitution UX et la Brand Identity validées.

L'objectif n'est pas simplement d'obtenir une interface "jolie".

L'objectif est de produire un SaaS premium, commercialisable et au niveau des meilleurs logiciels B2B du marché.

---

# OBJECTIF

Transformer progressivement KARATIX en une application SaaS moderne, professionnelle, élégante et haut de gamme.

Chaque écran doit donner immédiatement une impression de qualité, de confiance et de robustesse.

L'utilisateur doit ressentir que le logiciel est rapide, fluide, structuré et pensé dans les moindres détails.

---

# OBLIGATION

Avant d'écrire le moindre code :

Réutilise systématiquement les composants du Design System déjà créés.

Ne recrée jamais un composant existant.

Ne duplique jamais du code UI.

Toute nouvelle interface doit être construite uniquement avec les composants centralisés.

---

# IDENTITÉ VISUELLE

Respecte strictement :

- les Design Tokens
- les couleurs officielles
- les espacements
- les tailles
- les typographies
- les rayons
- les bordures
- les animations
- les ombres
- les états
- les composants UI

Aucune valeur magique.

Aucune couleur hardcodée.

Aucun padding arbitraire.

Aucune taille aléatoire.

# EXPÉRIENCE UTILISATEUR

Chaque page doit donner la sensation :

- de rapidité
- de fluidité
- de simplicité
- de maîtrise
- de confiance

Le logiciel doit disparaître derrière le métier.

---

# ANIMATIONS

Toutes les interactions doivent être vivantes mais discrètes.

Ajouter lorsque c'est pertinent :

• Hover subtil

• Focus élégant

• Transition fluide

• Fade In

• Fade Up

• Scale léger

• Micro-interactions

• Animation des cartes

• Animation des KPI

• Animation des graphiques

• Apparition progressive des sections

• Skeleton pendant les chargements

• Optimistic UI lorsque possible

Les animations doivent rester rapides :

150 à 250 ms maximum.

Jamais d'animation décorative.

Le mouvement doit uniquement améliorer la compréhension.

---

# RESPONSIVE

Chaque écran doit être parfait sur :

320 px

375 px

414 px

768 px

1024 px

1280 px

1536 px

Le responsive ne consiste jamais à cacher des éléments.

Il consiste à réorganiser intelligemment les informations.

---

# ACCESSIBILITÉ

Respect obligatoire :

- WCAG AA

- Navigation clavier

- Focus visible

- aria-label

- contraste

- zones tactiles ≥ 44 px

- messages d'erreur accessibles

---

# PERFORMANCE

Limiter :

- les re-render

- les composants inutiles

- les imports inutiles

- les styles redondants

- les animations coûteuses

Toujours privilégier la performance.

# QUALITÉ COMMERCIALE

Imagine que KARATIX sera vendu à des clubs professionnels.

Chaque écran doit être suffisamment qualitatif pour :

- être présenté dans une démonstration commerciale ;
- être utilisé sur le site officiel ;
- apparaître dans des captures marketing ;
- convaincre un futur client dès les premières secondes.

Chaque détail compte.

Le résultat attendu doit évoquer la qualité des meilleurs SaaS modernes comme Linear, Stripe, Notion, Vercel ou Raycast, tout en conservant une identité propre à KARATIX.
